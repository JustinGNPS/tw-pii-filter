# 示範頁面：怎麼跑起來

給組員的操作說明。跑起來大約三分鐘，**不需要 API 金鑰、不會連上任何雲端服務**。

---

## 這是什麼

一個本機網頁，把 proxy 平常只印在 log 裡的東西變成看得見的畫面：貼一段文字進去，
立刻看到偵測到什麼、遮蔽後長什麼樣、組合風險多少、花了幾毫秒。

**純本機運算**，不會把你貼進去的內容送到任何地方。

---

## 你需要什麼

| 項目 | 說明 |
|---|---|
| Python 3.11 | 專案指定版本 |
| 專案的 `.venv` | 照 `proxy/README.md` 的「安裝」一節建好 |
| `.env` | **這個示範不需要**（不會連上游）。沒有 `.env` 也跑得起來 |
| 語意層套件 | **不需要**。預設只跑規則層，不會 import torch/transformers |

---

## 啟動（三步）

**1. 切到有這個功能的分支**

```
git fetch --all --prune
git checkout feature/demo-page
```

> 合併進 `main` 之後這一步就不用了，直接 `git checkout main` 即可。

**2. 開 proxy，並打開示範開關**

命令提示字元（cmd.exe）：

```
set PII_ENABLE_DEMO=1
.venv\Scripts\python.exe -m uvicorn proxy.main:app --port 8010
```

PowerShell：

```powershell
$env:PII_ENABLE_DEMO = "1"
.venv\Scripts\python.exe -m uvicorn proxy.main:app --port 8010
```

看到這一行就代表成功了：

```
示範頁面：已啟用（/demo）
```

**3. 瀏覽器開**

<http://localhost:8010/demo>

結束時回到終端機按 `Ctrl + C` 關掉。

## 怎麼玩

頁面上有四個範例按鈕，各自展示不同的東西：

| 按鈕 | 看什麼 |
|---|---|
| **客服紀錄** | 最典型的情境：身分證與手機被換成佔位符，其餘文字一字不動 |
| **程式碼片段** | 貼程式碼給 AI 除錯時，裡面的客戶資料會被擋下來 |
| **錯誤訊息** | 信用卡號、API 金鑰、信箱、統編一次抓四種 |
| **只有準識別子** | **一個明碼個資都沒有**，右邊看起來跟左邊一模一樣 —— 但下面會跳出組合風險分數 |

自己動手更有感的三個試法：

1. **把身分證最後一碼改掉**（`A123456789` → `A123456788`）—— 它**不會被遮**，
   因為檢核碼過不了。這是我們相對於國外工具最能講的一點。
2. **同一個號碼打兩次** —— 會拿到同一個佔位符（`[TW_ID_1]`）。這是必要的：
   若同一個人在不同段落變成不同編號，AI 會以為那是不同的人。
3. **按「重設對照表編號」再掃一次** —— 編號從 1 重新開始。

## 常見問題

**姓名和地址為什麼沒被遮？**

語意層（NER）預設關閉，目前只有規則層在跑。狀態列的「語意層」會顯示
「未啟用（僅規則層）」。這是預期行為，不是壞掉 —— 語意層需要另外安裝
torch/transformers（GB 等級），而且單次推論要好幾百毫秒。

要開的話：`pip install -r core/ner/requirements.txt`，然後多設一個
`PII_ENABLE_NER=1`。

**我在我的電腦上開了，別人能連進來看嗎？**

**不行。** `localhost` 只有你自己這台機器連得到，這是瀏覽器與作業系統的
基本安全設計。每個人都要在自己的機器上跑一次。

（技術上可以讓它對外，但那等於「請別人把個資貼到你的伺服器上」，
跟本專案「資料不經第三方」的核心主張直接矛盾，所以不做。）

**這樣要怎麼展示給沒安裝的人看（例如評審）？**

現場 demo 就用自己的筆電跑這一頁。之後會另外做一份用**預錄資料**驅動的
靜態展示網站，可以掛到網路上 —— 那份看得到操作流程與結果，但數字是錄好的。

**它會不會消耗 API 額度、把我的資料傳出去？**

不會。示範頁面的所有運算都在本機完成，不會呼叫上游 LLM。頁面右上角
標示「本機 · 不送上游」。

**對照表那一區點開會看到明文個資，安全嗎？**

那是你自己剛剛貼進去的內容，只存在這個行程的記憶體裡，關掉 proxy 就消失。
但**投影或截圖給別人看之前記得收合**。

**為什麼預設要關閉？**

這個頁面會顯示未遮蔽的原文與對照表，而且提供一個不需認證就能呼叫偵測核心的
端點。平常跑 proxy 沒有理由開著它，所以要明確設 `PII_ENABLE_DEMO=1`。
沒開的時候 `/demo` 一律回 404。

---

## 這個頁面不做什麼

- **不參與轉發**。agent 走 proxy 的行為完全不受影響，開不開都一樣。
- **不共用對照表**。你在頁面上試打的內容，不會污染 agent 正在用的那張表
  （但「現況總覽」看的是真實的流量與對照表，因為那一區要回答的是
  「proxy 現在的狀態」）。
