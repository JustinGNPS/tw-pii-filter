## 1. 系統總覽：一個核心、兩個載體

核心概念只有一句：**個資在離開你的電腦之前就被換成佔位符，AI 回覆回來時才在本地換回真值。**
雲端 AI 從頭到尾只看到 `[TW_ID_1]`，看不到 `A123456789`。

```mermaid
flowchart LR
    subgraph LOCAL["你的電腦（資料不出裝置）"]
        U1["一般使用者<br/>在 ChatGPT 網頁貼上"] --> EXT["<b>載體一：瀏覽器擴充</b><br/>貼上攔截 → 確認面板 → 遮蔽<br/>回覆在本地還原"]
        U2["開發者<br/>用 AI coding agent"] --> PROXY["<b>載體二：API Proxy</b><br/>攔截請求 → 遮蔽 → 轉發<br/>回覆／串流在本地還原"]
        EXT --> CORE["<b>偵測核心</b><br/>L1 規則層＋檢核碼<br/>L2 語意層（選配）<br/>L4 衝突仲裁・L3 組合風險"]
        PROXY --> CORE
        CORE --- MAP[("對照表<br/>佔位符 ↔ 真值<br/>只存在本機")]
    end

    EXT <-- "去程只有佔位符<br/>回程在本地換回真值" --> CLOUD["雲端 AI<br/>ChatGPT / Claude / Gemini<br/>OpenAI 相容 API"]
    PROXY <-- "去程只有佔位符<br/>回程在本地換回真值" --> CLOUD
```

| 載體 | 給誰 | 攔截點 | 程式碼 |
|---|---|---|---|
| 瀏覽器擴充 | 一般使用者 | 網頁輸入框的 `paste` 事件 | `extension/` |
| API Proxy | 開發者 | LLM API 請求（不是 MCP） | `proxy/` |

攔截點選在 **LLM API 層**而不是 MCP，因為六款主流 agent 讀檔都走內建工具、不經過 MCP。
Aider / Continue / Cline / Codex / OpenCode / Claude Code 可攔；**Cursor 走自家後端，攔不到，誠實列為不支援。**

## 2. 偵測核心：四層架構

```mermaid
flowchart TB
    IN["輸入文字"] --> NORM["全形→半形正規化<br/>（Ａ１２３… → A123…，座標 1:1 不變）<br/>core/rules/normalize.py"]

    NORM --> L1["<b>L1 規則層</b>（core/rules/）<br/>身分證・統編・健保卡・手機・市話<br/>Email・信用卡・API 金鑰<br/><b>全部驗證檢核碼</b>"]
    IN --> L2["<b>L2 語意層</b>（core/ner/，選配）<br/>開源中文 NER 小模型，本機離線執行<br/>白名單只採信 NAME / ADDRESS / POSITION / COMPANY"]

    L1 --> L4["<b>L4 衝突仲裁</b><br/>core/rules/conflict_resolver.py<br/>重疊的 span 只留一個，保證互不重疊"]
    L2 -- extra_spans --> L4

    L4 --> OUT["spans<br/>（start, end, type, text, confidence, source）"]
    L4 --> L3["<b>L3 組合風險</b>（core/risk/）<br/>年齡＋性別＋地區＋職稱…<br/>單項不是個資，組合起來能指認一個人<br/>＋內政部人口統計估算群體大小"]
    L3 --> RISK["combination_risk<br/>score / 等級 / 泛化建議"]
```

**為什麼要驗檢核碼**：Presidio、GLiNER、LLM Guard 對台灣身分證與統編的 recall 都是 0.000，
而且沒有任何工具驗檢核碼 —— 任何「1 英文＋9 數字」都會被當成身分證，誤報率高到使用者會關掉工具。
我們驗，所以 `A123456788`（檢核碼錯）不會被誤判。

**為什麼語意層預設關閉**：模型約 389 MB、套件約 1 GB，而且延遲隨文字長度成長
（38 字 43 ms → 3040 字 2265 ms）。規則層只要 0.1～3 ms。

## 3. 載體一：瀏覽器擴充的完整流程

```mermaid
sequenceDiagram
    autonumber
    actor 使用者
    participant 網頁 as ChatGPT 網頁
    participant CS as 擴充 content script
    participant 核心 as 偵測核心（TS 版）
    participant 存放 as chrome.storage<br/>（本機）
    participant AI as 雲端 AI

    使用者->>網頁: Ctrl+V 貼上含個資的文字
    網頁->>CS: paste 事件（capture 階段搶先攔下）
    CS->>核心: detectAll(text)
    核心-->>CS: spans ＋ 組合風險

    alt 沒有個資、也沒有組合風險
        CS->>網頁: 原文照常貼上（完全不打擾）
    else 偵測到個資或組合風險
        CS->>使用者: 確認面板（逐項勾選，預覽佔位符）
        alt 遮蔽後貼上
            CS->>存放: 以「對話」為單位配號（同值同碼）
            CS->>網頁: 貼上遮蔽版 「身分證 [TW_ID_1]」
        else 直接貼原文
            CS->>網頁: 貼上原文（使用者有最終決定權）
        else 取消
            CS-->>使用者: 什麼都不貼
        end
    end

    使用者->>AI: 送出（AI 只收到佔位符）
    AI-->>網頁: 回覆「已為 [TW_ID_1] 填寫…」

    Note over CS,網頁: 回覆還原（restorer.ts）
    CS->>存放: 讀這個對話的對照表
    CS->>網頁: 把回覆裡的佔位符換回真值並標綠<br/>（輸入框一律不碰）
    使用者->>CS: 點右下角開關
    CS->>網頁: 切回「AI 收到的版本」（佔位符）
```

**幾個刻意的設計：**

- **攔 `paste` 不攔右鍵選單**：不需要 `clipboardRead` 權限，而且使用者照常 Ctrl+V 就被保護。
- **新對話會換網址**（`/` → `/c/<id>`）：送出第一則訊息後，配號狀態跟著搬到新網址，
  否則還原會找不到對照表。只在「從新對話頁跳過去」時才搬，避免拿錯對話的對照表。
- **AI 自己編的佔位符**（例如從沒發過的 `[TW_ID_9]`）**原樣保留、絕不猜測**。

## 4. 載體二：AI Agent 防護（API Proxy）的完整流程

```mermaid
sequenceDiagram
    autonumber
    actor 開發者
    participant Agent as AI coding agent<br/>（Codex / Aider / Cline…）
    participant P as API Proxy<br/>127.0.0.1:8000
    participant 核心 as 偵測核心（Python）
    participant 表 as 對照表（記憶體）
    participant AI as 雲端 LLM API

    開發者->>Agent: 「幫我整理 customers.csv」
    Agent->>Agent: 用內建工具讀檔（內容含身分證、電話）
    Agent->>P: POST /v1/chat/completions<br/>（含檔案內容）
    P->>P: 從 payload 挖出要掃的欄位<br/>（messages / tool 結果 / Responses API / Anthropic 格式）
    P->>核心: detect（有快取，重送的歷史不重算）
    核心-->>P: spans
    P->>表: 配號（同值同碼，跨輪一致）
    P->>P: 從後往前替換，座標不位移
    P->>P: 組合風險警示（選配：自動降階）
    P->>AI: 轉發遮蔽後的請求（只有佔位符）

    AI-->>P: SSE 串流回覆（含佔位符）
    loop 每個串流片段
        P->>表: 查佔位符
        P->>P: 換回真值<br/>（佔位符被切在兩個封包之間也接得起來）
        P-->>Agent: 還原後的片段
    end
    Agent->>Agent: 依回覆寫檔（寫進磁碟的是真值）
    Agent-->>開發者: 完成
```

**驗證過的事實（實際跑 Codex 的紀錄，2026-08-22）**：agent 把自己寫的檔案讀回來時，
規則層在裡面**又抓到一個身分證** —— 若還原失效，檔案裡會是 `[TW_ID_1]`，不可能被判成身分證。
這是從磁碟上的位元組倒推回來的證據，不是 log 宣稱的。

**一定要確認流量真的有經過 proxy**：設定沒生效時 agent 會安靜地直連雲端，畫面上沒有任何警告。
所以 proxy 會在第一個請求抵達時印一行「第一個請求已抵達 proxy」，`/healthz` 也看得到請求數。

```mermaid
flowchart LR
    A["agent 開始工作"] --> B{"proxy log 有出現<br/>「第一個請求已抵達」？"}
    B -- 有 --> C["✅ 有受保護"]
    B -- 沒有 --> D["❌ agent 沒接過來<br/>資料直接送去雲端了"]
    D --> E["檢查 agent 的 base URL<br/>是否為 http://127.0.0.1:8000/v1"]
```

## 5. 對照表的生命週期

對照表是一份「佔位符 ↔ 真值」的明文清單，**本身就是集中的個資，是攻擊面**。
所以它只存在本機、有作用域、會自動過期。

```mermaid
stateDiagram-v2
    [*] --> 空的: 啟動 proxy／開新對話
    空的 --> 有內容: 第一次遮蔽到個資
    有內容 --> 有內容: 新的值 → 配新號<br/>同一個值 → 沿用舊號
    有內容 --> 空的: Proxy：閒置 30 分鐘自動清空<br/>擴充：12 小時過期
    有內容 --> [*]: 關掉 proxy（只在記憶體，不落地）
```

| | API Proxy | 瀏覽器擴充 |
|---|---|---|
| 存在哪 | 行程記憶體（不寫檔） | `chrome.storage.local`（本機） |
| 作用域 | 整個 proxy 行程 | **單一對話**（換對話就換一組號碼） |
| 過期 | 閒置 30 分鐘清空（`PROXY_MAPPING_IDLE_TIMEOUT`） | 12 小時 |
| 為什麼作用域不同 | agent 每輪重送全部歷史，必須跨請求一致 | 跨對話一致的假名等於造了一個追蹤識別子 |

## 6. 使用者工作流：誰該用哪一個

```mermaid
flowchart TD
    Q{"你平常怎麼用 AI？"}
    Q -- "在 ChatGPT / Claude / Gemini 網頁聊天" --> E["安裝瀏覽器擴充<br/>（啟動.bat → [2]）"]
    Q -- "用 AI coding agent 寫程式" --> P["啟動 API Proxy<br/>（啟動.bat → [1]）<br/>並把 agent 的 base URL 指過來"]
    Q -- "只是想先看看效果" --> W["開線上 Demo 網站<br/>（啟動.bat → [3]）<br/>不用安裝任何東西"]

    E --> E1["照常貼上 → 面板確認 → 送出<br/>回覆自動還原"]
    P --> P1["照常使用 agent<br/>示範頁「即時監看」看背景在做什麼"]
    W --> W1["貼任意文字，即時看到偵測與遮蔽<br/>（全部在你的瀏覽器裡算，不上傳）"]

    P1 --> NER{"需要認姓名、地址？"}
    NER -- 是 --> N1["啟動時選擇開啟語意層<br/>（約 1 GB，第一次需下載）"]
    NER -- 否 --> N2["只用規則層<br/>（延遲 < 3 ms）"]
```

| 角色 | 用什麼 | 需要安裝 |
|---|---|---|
| 一般上班族、學生 | 瀏覽器擴充 | Chrome |
| 開發者 | API Proxy | Python 3.11 |
| 想認姓名地址的人 | Proxy ＋ 語意層 | 再加約 1 GB 套件 |
| 評審、參觀者 | 線上 Demo 網站 | 不用 |

## 7. Demo Day 現場展示動線

2026-11-08（日）政大公企中心，13:00 前報到、13:30 起評比。形式是**展覽式擺攤**，現場有網路。
每位參觀者停留時間不長，動線設計成「30 秒看懂、3 分鐘看完、想深入可以一直挖」。

```mermaid
flowchart TD
    START(["參觀者走到攤位"]) --> HOOK["① 30 秒：海報＋一句話<br/>「你貼給 ChatGPT 的身分證，<br/>現有工具 recall 是 0」"]
    HOOK --> TRY["② 1 分鐘：請他自己在 ChatGPT 貼上<br/>（筆電 A，已裝擴充）<br/>→ 跳出確認面板 → 遮蔽後送出"]
    TRY --> RESTORE["③ AI 回覆自動還原成真值（標綠）<br/>→ 按右下角開關<br/>→ 「這才是 ChatGPT 實際收到的」"]
    RESTORE --> DEEP{"參觀者是開發者／評審<br/>想看更深？"}
    DEEP -- 是 --> AGENT["④ 筆電 B：agent 防護<br/>示範頁「即時監看」＋讓 agent 讀含個資的檔案<br/>→ 看 log 逐筆遮蔽、還原"]
    DEEP -- 否 --> END
    AGENT --> CHECK["⑤ 檢核碼對比：在試打台輸入<br/>A123456789（對）與 A123456788（錯）<br/>→ 只有對的被抓，錯的說明為什麼"]
    CHECK --> RISK["⑥ 組合風險（需開語意層）：輸入<br/>「我是35歲女性，住在台北市，職業是護理師」<br/>→ 沒有身分證也沒有電話，風險卻是 1.0（高）<br/>→ 台北市 35 歲女性最多 15,689 人，再加上職稱更少"]
    RISK --> END(["掃 QR code 帶走線上 Demo 網址"])

    NET{{"網路掛了？"}} -.-> OFFLINE["備援：示範頁「試打台」完全離線可用<br/>（遮蔽＋還原＋語意層都在本機跑）"]
```

**現場前一天檢查清單**

- [ ] 筆電 A：Chrome 已載入最新版擴充（`啟動.bat` → `[2]` → 擴充卡片按「重新載入」）
- [ ] 筆電 A：ChatGPT 已登入，開一個新對話備用
- [ ] 筆電 B：`啟動.bat` → `[1]`，語意層選「開啟」，示範頁能打開
- [ ] 筆電 B：`.env` 已填上游金鑰，agent 指令已在 cmd 視窗準備好
- [ ] 兩台都測過一次「拔掉網路」時試打台仍能用
- [ ] 線上 Demo 網址的 QR code 印在海報上
