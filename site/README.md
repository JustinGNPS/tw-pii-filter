# 靜態展示網站

把連結丟給別人（評審、老師、同學）點開就能試用的線上展示頁。

## 這是什麼、不是什麼

**是**：一個**純靜態**的對外展示頁。偵測、遮蔽、配號三件事全部 import 自
`extension/src/`——也就是瀏覽器擴充正在用的同一份 TypeScript 實作。
因此頁面上看到的結果，與使用者實際安裝擴充後得到的結果是同一套程式算出來的。

**不是**：第三個載體，也不是 `proxy/demo_page.html` 的替代品。
那一頁需要啟動 proxy、看得到真實流量與對照表狀態，是**給團隊內部**用的；
這一頁不需要任何後端，是**給外部的人**用的。

## 為什麼刻意沒有後端

本作品的核心主張是「資料不出裝置」。展示頁若把使用者貼進來的文字送到伺服器
去掃描，主張當場破功。所以這頁沒有任何 `fetch`／XHR，打包後是一個可以
離線雙擊開啟的 HTML 檔。

## 為什麼不另外寫一份「展示用的簡化偵測」

那會讓這個頁面變成行銷素材而不是證據。直接用擴充的實作，而那份實作又有
`extension/tests/parity.test.ts` 在把關它與 Python 版一致——
頁面上的每個結果都站得住腳。

## 範例資料的選用原則

身分證與統編的檢核碼**必須有效**，否則偵測器會正確地不理它、展示反而失敗。

但本專案的 `.gitignore` 明文規定：checksum 驗得過的合成號碼不進公開 repo
（「格式與真號無異，等同散布一份可直接使用的身分證號清單」）。

因此範例**不用隨機產生的號碼**，一律採用早已通行的教科書測試值：

| 值 | 來源 |
|---|---|
| `A123456789` / `B123456780` | 各種教學文件的標準身分證範例 |
| `12345675` / `98765438` | 順號與疊號，一眼看得出是假的 |
| `4111111111111111` | Visa 官方公告的測試卡號 |

它們本來就是公開的測試值，不構成「新散布一批可用號碼」。

## 這頁跑規則層（L1）與組合風險（L3），沒有語意層（L2）

語意層需要下載 NER 模型權重（數百 MB），不適合放進網頁，頁面上以標明出處的
實錄呈現。組合風險用的是擴充的 TypeScript 移植（`detectAll()` 回傳的
`combination_risk`），但少了語意層，能計入的準識別子只有年齡與性別，
分數會比完整系統低。**頁面上已明確標示這件事**，不假裝這裡展示的是完整系統。

## 版面編排

第一屏就是可以操作的試用區（送出前遮蔽、回覆後還原兩步），其餘內容依序是
「為什麼需要」「怎麼運作」「完成度與限制」。兩個載體與語意層收在同一組分頁裡，
分頁上標明「可操作」或「實錄」；細節（偵測明細、測試方法、agent 相容表、
導入步驟）預設收合。

## 建置

```
cd site
npm install      # 第一次
npm run build    # → dist/index.html
```

產出是**單一 HTML 檔**（約 56 KB），JS 直接內嵌在 `<script>` 裡。
單一檔案可以放任何靜態主機、可以用 email 寄、可以離線開啟，
不會有相對路徑或 MIME type 設錯導致白畫面的問題——展示場合最不需要的就是這種意外。

`esbuild` 版本與 `extension/package.json` **鎖同一個**（0.21.5）：
兩邊打包的是同一份原始碼，版本不同可能讓產物有差異，
「網頁上看到的跟擴充實際行為一致」那句話就不成立了。
（CONTRIBUTING.md 第 6 條：套件版本鎖死。）

## 本機預覽

```
cd site/dist
python -m http.server 8777
```

然後開 http://127.0.0.1:8777/
（直接用瀏覽器開 `file://` 也可以，這頁沒有任何跨來源請求。）

## 部署

`dist/index.html` 是唯一需要部署的檔案，放到任何靜態主機的根目錄即可。
