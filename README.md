# 本地端敏感資訊過濾機制

面向 AI 應用場景的即時去識別化系統。在資料送往雲端 AI 之前，於本地端完成敏感資訊偵測與可逆處理，AI 回覆時自動還原，資料不經任何第三方伺服器。

## 這個專案在做什麼

現有隱私防護工具對台灣個資（身分證字號、統一編號）幾乎無法偵測。我們實測發現，多數方案在這些格式上的偵測率為 0，且無法驗證檢核碼真偽。本專案補足這個缺口。

## 兩個載體，一個核心

- **偵測核心**：規則驗證（checksum）+ 語意偵測（NER）+ 組合風險評分
- **瀏覽器擴充**：右鍵選單「隱私處理後貼上」，面向一般使用者
- **AI coding agent 防護**：API Proxy 攔截，面向開發者

## 團隊分工

| 角色 | 負責 |
|---|---|
| A | 規則層與系統架構 |
| B | Agent 防護與還原機制 |
| C | 瀏覽器擴充 |
| D | 語意層、組合風險評分與評估 |
